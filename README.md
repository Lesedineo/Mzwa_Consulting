
# Mzwa_Consulting

Short static website project for Mzwa Consulting.

## Description

This repository contains a small static website for Mzwa Consulting. It includes a landing page and an about page, and is intended as a simple informational site to showcase services, contact details, and company information.

## Languages & Technologies

- HTML — structure and content (index.html, about.html)
- CSS — styles (included inline or in separate stylesheets if added)
- JavaScript — optional interactivity (add scripts in `scripts/` or inline)

## File Structure

- [index.html](index.html) — main landing page
- [about.html](about.html) — about / company information
- README.md — this file

If you add styles or scripts, consider creating `css/` and `js/` folders for organization.

## Setup & Usage

1. Clone or download the repository.
2. Open `index.html` in a web browser to view the site locally.

For a simple local preview using Python (optional):

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

## Development

- To add a new page, create an HTML file and link it from the navigation.
- Place CSS in a `css/` folder and JavaScript in a `js/` folder for clarity.
